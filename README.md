# 駐車場 共有マップ - 使い方

お金をかけず、社内Wi-Fi（インターネット接続なし）だけで動く駐車場管理アプリです。
Pythonさえ入っていれば追加インストール不要で動きます。

## 必要なもの
- Python 3 がインストールされたPC、または Android スマホ + Termuxアプリ（無料）
- 全員が同じ社内Wi-Fiに接続していること

---

## 【PCで動かす場合】（Windows / Mac）

1. `parking_app` フォルダをPCに置く
2. ターミナル（Mac）またはコマンドプロンプト（Windows）を開き、フォルダに移動
   ```
   cd parking_app
   ```
3. サーバーを起動
   ```
   python3 server.py
   ```
   （Windowsで `python3` が動かない場合は `python server.py`）
4. 画面に表示される URL（例: `http://192.168.1.23:8000`）をメモする
5. 同じWi-Fiに繋がっている他の人のスマホ・PCのブラウザでそのURLを開けば、
   みんなが同じ駐車場マップを見たり編集したりできます

※ このPCがスリープしたり、ターミナルを閉じたりするとサーバーは止まります。
　 朝に起動して、終業時に Ctrl+C で止める運用がおすすめです。

---

## 【スマホ（Android）だけで動かす場合】

1. Google Playで **Termux** をインストール（無料）
2. Termuxを開き、以下を1回だけ実行（Python導入）
   ```
   pkg install python -y
   ```
3. `parking_app` フォルダの中身（server.py, index.html）をスマホの
   `~/parking_app/` などに置く（PCからAirDropやUSB、ファイル共有アプリ等で転送）
4. Termuxで起動
   ```
   cd ~/parking_app
   python server.py
   ```
5. 表示されたURLに、同じWi-Fi内の他の端末からアクセス

※ iPhoneには同等の無料アプリ（a-Shell等）がありますが、設定がやや異なります。
　 基本的には「常時電源が入れっぱなしになりやすいPC」で動かすのが一番安定します。

---

## 駐車枠・車両リストの変更方法

`server.py` を開き、上の方にある `DEFAULT_DATA` の部分を書き換えてください。

```python
DEFAULT_DATA = {
    "slots": ["A1", "A2", "A3", "A4", "B1", "B2", "B3", "B4"],  # 枠の名前
    "vehicles": [
        {"id": "v1", "name": "トヨタ プリウス", "plate": "品川 300 あ 12-34"},
        ...
    ],
    "assignments": {},
}
```

枠の数や車両は自由に増減できます。
変更後、既に `parking_data.json` が出来ている場合は一度削除してから再起動すると
新しいリストが反映されます（駐車状況の記録もリセットされます）。

## よくある質問

**Q. 複数人が同時に操作しても大丈夫？**
A. はい。データはサーバー役の端末上の `parking_data.json` に保存され、
　 全員が3秒ごとに自動で最新状態を取得するので、ほぼリアルタイムに反映されます。

**Q. インターネットは必要？**
A. 不要です。同じWi-Fi（ルーター）に繋がっていれば、外部回線が無くても動作します。

**Q. サーバー役の端末を変えたい**
A. `parking_app` フォルダ（`parking_data.json` も含めて）を新しい端末にコピーすれば、
　 そのまま続きから使えます。
